# System Design Trade-off Cheat Sheet

---

## Consistency vs Availability
- Banking → Consistency
- Feeds → Availability

---

## SQL vs NoSQL
- Transactions → SQL
- Scale → NoSQL

---

## Sync vs Async
- Critical path → Sync
- Background work → Async

---

## Cache vs DB
- Speed → Cache
- Durability → DB

---

## Monolith vs Microservices
- Early stage → Monolith
- Scale + teams → Microservices

---

## Senior Rule

Always explain:
"What I gain"
"What I lose"
"Why it is acceptable"
