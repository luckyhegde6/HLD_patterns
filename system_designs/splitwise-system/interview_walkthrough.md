# Interview Walkthrough

1. Clarify split types, currencies and edit semantics.
2. Design ledger and balance projection.
3. Walk expense creation and deterministic split calculation.
4. Explain rounding, idempotency and projection rebuild.
5. Cover settlement and access control.
6. Discuss debt simplification trade-offs.

Follow-ups: multi-currency? edits? rounding? projection outage?
