# Interview Walkthrough

1. Clarify flag types and evaluation latency.
2. Design control plane and SDK data plane.
3. Explain targeting, stable bucketing and versioning.
4. Define offline behavior and safe defaults.
5. Cover privacy, audit, rollout and cleanup.
6. Explain experiments and guardrail metrics.

Follow-ups: stale config? SDK version skew? kill-switch propagation? targeting PII?
