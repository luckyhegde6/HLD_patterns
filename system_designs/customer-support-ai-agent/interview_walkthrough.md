# Interview Walkthrough

1. Define issue workflow, channels, actors and resolution criteria.
2. Clarify tenant authorization and sensitive action classes.
3. Draw intake, retrieval, orchestration, policy/tool runtime and approval components.
4. Walk authorized retrieval and evidence-linked proposal.
5. Explain typed tools, idempotency, approval and audit.
6. Model timeout-after-write, CRM outage, prompt injection and missing evidence.
7. Define resolution accuracy, handling time, escalation rate and safety metrics.
8. Explain rollout from read-only to governed tools and canary.

Follow-ups: tenant isolation proof? approval invalidation? ambiguous tool outcome? unsafe deflection? kill switch? golden set and PII handling?
