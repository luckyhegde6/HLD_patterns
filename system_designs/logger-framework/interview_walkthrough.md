# Interview Walkthrough

1. Estimate event volume, size and retention.
2. Design SDK, collector, durable buffer and sinks.
3. Explain schema evolution, redaction and sampling.
4. Cover backpressure, loss policy and replay.
5. Discuss query indexing, cardinality and cost.
6. Explain audit/security separation and SLOs.

Follow-ups: collector outage? hot tenant? schema drift? retention deletion?
