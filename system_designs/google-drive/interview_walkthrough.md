# Interview Walkthrough — Google Drive

Clarify file size/count, sharing, sync freshness, version history, collaboration and deletion. Estimate stored bytes, upload throughput and sync events. Define upload/finalize, download, ACL and change-feed APIs. Draw chunk upload, metadata commit and sync. Deep dive concurrent versions, revocation, malware scan, cursor expiry and restore. Close with ACL correctness, sync lag, storage cost and recovery SLOs.
